# Security policy

## Supported versions

Only the latest release built from `main` is supported.

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately with GitHub's
**"Report a vulnerability"** button on the Security tab of this repository
(<https://github.com/Arffornia/Arffornia_Launcher_V.5.2/security/advisories/new>).

Include what is affected, how to reproduce it and the impact. You will get an answer as soon as the
maintainer can look at it. Please give us reasonable time to ship a fix before disclosing it.
